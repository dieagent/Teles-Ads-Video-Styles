## Style lock

- **Opening:** Begin inside an already dangerous room, with the character and flames visible at once.
- **Image grammar:** Glossy 3D human reenactment; orange fire, black smoke, reflective floor, dark interior. Alternate a full body and extreme hand/door details. White lowercase captions sit near the bottom.
- **Story grammar:** Second-person conditional instruction: immediate safe movement → inspect the door → explain the danger if it is hot → show an alternate exit → show the cool-door route.
- **Edit grammar:** The narrator’s words dictate the close-ups: body on “get low,” hand on “check,” door crack on “smoke,” window on the alternate route. Cut back to the human between object inserts.
- **Sound grammar:** Urgent but calm spoken instruction; constant low fire roar, small hand/door cues. The fire must never drown out the command.
- **Target:** approximately 33 s, 9:16, unless the spoken draft needs a different runtime.

## Make the video

Write an original script for the user’s topic using the same sequence of *functions* as the reference. Build a table of exact words, shot, camera/object motion, caption and sound. Record or obtain voice takes, measure them, then lock shots to the actual voice. Start each meaningful image at the phrase it illustrates; never pad narration with unrelated static background. Create original art or footage in the reference’s visual grammar without copying reference frames. Render a draft, watch and listen end to end, then correct timing, captions, visual relevance, motion and mix before handing over the final.

Safety guidance is consequential. Verify each instruction with an authoritative safety source before making a factual video.
