# Teles Ads

Twelve short-video style commands, built on a copy of Arc Lab Series v1.0.2. Ten treatments come from the ten supplied clips; two are explicitly identified hybrids. Each command has a skill, an observed breakdown, a worked example, a source clip and screenshot references.

Run a command in Claude Code from this repository, for example `/zackd why I'm afraid`. The command files are in `.claude/commands/`; the detailed skill files are in `.claude/skills/`. If using a client that does not expose repository commands, open the matching `SKILL.md` and supply the same topic.

## Quality bar

The scripts should be concise and spoken naturally. Record the voice before committing picture timing. Every shot must be tied to a phrase or a deliberate sound-only beat. Check the export end to end with sound, especially captions, music level, image relevance and the last frame. Source clips are for study; generated videos need their own visuals and verified factual claims.
